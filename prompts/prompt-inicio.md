# Prompt de inicio

> Cópialo y pégalo al abrir Claude Code en una carpeta nueva. Te garantiza que Claude entiende el contexto antes de tocar nada.

```
Lee esta carpeta como contexto de proyecto.

No modifiques archivos todavía.

Quiero que primero me devuelvas:
1. Qué entiendes del objetivo
2. Qué inputs has encontrado
3. Qué información falta
4. Riesgos o ambigüedades
5. Plan recomendado en pasos

Escribe para una persona no técnica.
```

## Variantes

**Si estás en Plan Mode (recomendado):**
```
Lee esta carpeta y propón plan para [tarea X]. Sin tocar archivos. Espero tu plan antes de aprobar.
```

**Si quieres más profundidad:**
```
Lee esta carpeta y prepárate para una sesión de trabajo. Necesito que entiendas:
- Qué proyecto es
- Quién es el cliente / audiencia
- Qué entregables esperamos
- Qué restricciones hay
- Cuál es mi rol (ejecutor / revisor / aprobador)

No toques nada. Devuélveme tu comprensión y pregúntame lo que falta.
```
