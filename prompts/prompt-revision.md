# Prompt de revisión

> Para revisar un entregable antes de presentárselo a un cliente o aprobarlo internamente.

```
Revisa el entregable [archivo X] como si fueras un consultor senior antes de enseñarlo a un cliente.

Evalúa contra estos criterios:
- Claridad: ¿se entiende sin explicación adicional?
- Utilidad: ¿resuelve el problema real del cliente?
- Precisión: ¿hay datos sin respaldar o contradicciones?
- Riesgos: ¿qué podría salir mal si el cliente actúa sobre esto?
- Suposiciones: ¿qué hemos asumido y no validado?
- Próxima acción: ¿qué se espera que el cliente haga después?
- Tono: ¿es apropiado para esta audiencia?

Dame:
1. Puntuación 1-10 con justificación
2. Top 3 mejoras prioritarias (con propuesta concreta de cómo aplicar cada una)
3. Si la puntuación es <7, una versión mejorada del documento

No me digas que está "bien" si no lo está. Sé exigente.
```

## Variante: revisor "cliente escéptico"

```
Actúa como [tipo de cliente: CFO de una pyme / responsable de marketing / director de operaciones]. Eres escéptico, has visto muchas propuestas vacías, y solo te interesa lo que realmente funciona.

Lee este entregable y dime:
1. ¿Qué objeciones te pondrías tú?
2. ¿Qué frase concreta te haría descartar la propuesta?
3. ¿Qué te haría decir "vamos a hacerlo"?

Sé incómodo. Tu trabajo es proteger al cliente, no hacer feliz al consultor.
```
