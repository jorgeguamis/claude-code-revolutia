# Prompt para explicar a cliente no técnico

> Cuando tienes un documento técnico o denso y necesitas la versión "para enviar al cliente".

```
Convierte este documento en una explicación para [cliente / dirección / equipo no técnico].

Debe ser:
- Clara: cualquier persona no técnica entiende
- Breve: máximo [X] palabras o [Y] páginas
- Orientada a negocio: foco en impacto, no en cómo está hecho
- Sin jerga innecesaria: si tienes que usar un término técnico, explícalo en una frase
- Con próximos pasos concretos: qué se espera que haga el cliente

Mantén:
- Datos reales y números (no los redondees a la baja)
- Riesgos importantes (no los suavices)
- Lo que necesita decisión del cliente

Quita:
- Detalles técnicos innecesarios
- Justificaciones largas
- Acrónimos no explicados
```

## Versión "ejecutivo"

```
Genera una versión ejecutiva de este documento. Máximo 1 página.

Estructura:
1. Resumen en 3 frases (qué propones, por qué, qué necesitas)
2. Hallazgos principales (3-5 bullets)
3. Recomendación (1 párrafo)
4. Próximos pasos (3 acciones concretas con responsable y plazo)

Tono: directo, factual, sin marketing.
```
